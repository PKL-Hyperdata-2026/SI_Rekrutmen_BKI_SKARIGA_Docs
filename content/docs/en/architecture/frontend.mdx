The SI Rekrutmen BKI SKARIGA frontend is a Single Page Application (SPA) built on **React 19** and **TypeScript 6**, bundled with **Vite 8** and running on the **Bun 1.3+** runtime.

## Core Technologies

- **Framework / Runtime:** React 19, TypeScript 6, Vite 8, Bun
- **Styling:** Tailwind CSS v4 (`src/index.css`), Geist font, Shadcn UI / Radix primitives
- **State Management:** Redux Toolkit (`authSlice.ts`), Sanctum Bearer token in `localStorage`
- **Routing:** React Router v7 (`src/route.tsx`), `ProtectedRoute`
- **Forms & Validation:** React Hook Form + Zod
- **Tables & Data:** TanStack React Table (`DataTable`)
- **Rich Text:** TipTap Editor suite
- **Testing:** Vitest

## Feature Module Pattern (Feature Modularization)

Features are grouped by user role (`src/features/{role}/{feature}/`):

```text
src/features/
├── auth/           # Login, Forgot Password, Reset Password, ProtectedRoute
├── student/        # Dashboard, E-Portfolio, Job Vacancy, My Applications, Tracer Study
├── hrd/            # Dashboard, Job Vacancy, Applicant Review, Test Schedule, Selection Results, Placement
└── admin/          # Dashboard, Students, Alumni, Partner Company, Major, Department, Selection, Reports, Users
```

Every feature follows a consistent file structure:
- `{feature}.api.ts`: Backend endpoint calls through the Axios client.
- `{feature}.schema.ts`: Zod validation schemas and TypeScript type inference.
- `{feature}.form.ts`: Custom form hook (`useForm` + default values + payload builders).
- `{feature}-page.tsx`: Main page component (container).
- `{feature}-table.tsx`: Table column and action definitions.
- `{feature}-form.tsx`: Presentational form component.

## UI Motion Standards

Interface transitions and animations follow the `/ui-motion` specification:
- Animate hardware-accelerated properties: `transform` and `opacity`.
- Custom cubic-bezier easing curve tokens:
  - `--ease-out`: `cubic-bezier(0.23, 1, 0.32, 1)` for dialogs, dropdowns, and popovers.
  - `--ease-drawer`: `cubic-bezier(0.32, 0.72, 0, 1)` for sheet drawers.
  - `--ease-in-out`: `cubic-bezier(0.77, 0, 0.175, 1)` for on-screen element movement.
- Responsive durations: active button 100-150ms, dropdown 150-180ms, modal 200-250ms, page transition 160ms (`.page-enter`).
- Accessibility protection through `@media (prefers-reduced-motion: reduce)`.
