This guide is for developers and AI agents who need to run, develop, and maintain the BKI SKARIGA Recruitment application consistently.

## Environment Prerequisites

- **PHP:** Version 8.3 or higher with the `pdo_pgsql`, `pgsql`, `mbstring`, and `fileinfo` extensions.
- **Database:** PostgreSQL 15+ (standard port 5432).
- **Composer:** Version 2.7+.
- **JavaScript Runtime & Package Manager:** Bun 1.3+ (or Node.js 22+).
