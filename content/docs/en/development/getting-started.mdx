This page walks you through setting up and running every **SI Rekrutmen BKI SKARIGA** service in a local (development) environment.

## Prerequisites

Make sure the following tools are installed on your machine:

- **PHP 8.3+** (ensure the `pdo_pgsql`, `pgsql`, `mbstring`, and `fileinfo` extensions are enabled in `php.ini`)
- **Composer** (the PHP package manager)
- **PostgreSQL 15+** (running on the default port `5432`)
- **Bun 1.3+** (the JavaScript runtime and package manager)

---

## 1. Backend Setup (Laravel 13 API)

Open your first terminal and navigate to the `backend` folder:

```bash
cd backend
composer install
copy .env.example .env
php artisan key:generate
```

Open the `.env` file and adjust your PostgreSQL database credentials:

```ini
DB_CONNECTION=pgsql
DB_HOST=127.0.0.1
DB_PORT=5432
DB_DATABASE=si_rekrutmen_bki_skariga_db
DB_USERNAME=postgres
DB_PASSWORD=password_postgres_kamu
```

Run the table migrations along with the initial data seeders:

```bash
php artisan migrate --seed
```

### Run the Backend (One-Line Command)
Use the following one-line command to start the HTTP server (`serve`), the email queue worker (`queue:work`), and the real-time WebSocket server (`reverb:start`) all at once in a single terminal:

```bash
php artisan dev
```

If you only want to run the HTTP server on its own:

```bash
php artisan serve
```

The backend server runs at `http://localhost:8000`.

---

## 2. Frontend Setup (React 19 + Bun + Vite+)

Open a second terminal and navigate to the `frontend` folder:

```bash
cd frontend
bun install
copy .env.example .env
```

Make sure the frontend `.env` points to your local backend:

```ini
VITE_API_URL=http://localhost:8000/api
VITE_BASE_URL=/
VITE_PORT=5173
```

Start the development server with Bun and the **Vite+** engine (`vp dev`):

```bash
bun run dev
```

The Vite+ development server comes up right away at `http://localhost:5173`.

---

## 3. Documentation Setup (Fumadocs)

Open a third terminal to run this documentation site:

```bash
cd documentation
bun install
bun run dev
```

The documentation opens at `http://localhost:3000`.

|---|---|---|---|
| **Backend (One-Line All-in-One)** | `/backend` | `php artisan dev` | HTTP server + queue + WebSockets |

| **Documentation (Fumadocs)** | `/documentation` | `bun run dev` | `http://localhost:3000` |

## Running the Automated Tests

Before opening a pull request or making a commit, make sure the whole test suite passes:

```bash
# Run the entire backend test suite (Pest PHP)
cd backend
php artisan test

# Run the entire frontend test suite (Vitest)
cd frontend
bun run test

# Check TypeScript types and build the frontend bundle
bun run build
```
