Panduan ini ditujukan bagi pengembang dan AI agent untuk menjalankan, mengembangkan, dan memelihara aplikasi SI Rekrutmen BKI SKARIGA secara konsisten.

## Prasyarat Lingkungan

- **PHP:** Versi 8.3 ke atas dengan ekstensi `pdo_pgsql`, `pgsql`, `mbstring`, `fileinfo`.
- **Database:** PostgreSQL 15+ (port standar 5432).
- **Composer:** Versi 2.7+.
- **JavaScript Runtime & Package Manager:** Bun 1.3+ (atau Node.js 22+).
