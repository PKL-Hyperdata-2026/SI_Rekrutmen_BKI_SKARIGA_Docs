---
title: Endpoint Admin BKK & Superadmin
description: Spesifikasi endpoint untuk modul Administrator BKK dan Superadmin
---

Endpoint berikut diakses oleh akun ber-role `admin` atau `superadmin`.

## Master Data Sekolah & DUDI

- `/api/admin/students`: CRUD master data siswa aktif kelas 12.
- `/api/admin/alumni`: CRUD master data alumni (termasuk fitur upgrade siswa menjadi alumni).
- `/api/admin/companies`: CRUD data mitra perusahaan DUDI dan toggle status aktif.
- `/api/admin/departments`: CRUD data departemen vokasi.
- `/api/admin/majors`: CRUD data kompetensi keahlian / jurusan.

## Monitoring Seleksi & Presensi

- `GET /api/admin/recruitment-selections`: Rekapitulasi progres seleksi seluruh lowongan secara view-only.
- `GET /api/admin/attendances/queue`: Antrean presensi peserta tes seleksi yang menunggu validasi petugas BKK.
- `GET /api/admin/attendances/history`: Riwayat presensi peserta yang telah divalidasi.
- `PATCH /api/admin/attendances/{id}/validate`: Validasi kehadiran satu peserta.
- `PATCH /api/admin/attendances/bulk-validate`: Validasi kehadiran massal.

## Rekapitulasi Laporan (`/api/admin/reports`)

- `GET /api/admin/reports/options`: Opsi filter tahun ajaran, jurusan, dan rentang tanggal.
- `GET /api/admin/reports/recruitment`: Laporan statistik rekrutmen dan rasio kelulusan per perusahaan.
- `GET /api/admin/reports/attendance`: Laporan tingkat kehadiran peserta seleksi.
- `GET /api/admin/reports/absorption`: Laporan keterserapan kerja siswa kelas 12 dan alumni.
- `GET /api/admin/reports/tracer-study`: Laporan tracer study, masa tunggu, dan sebaran wilayah kerja.

## Manajemen Pengguna (`/api/admin/users`) *(Khusus Superadmin)*

- `GET /api/admin/users`: Daftar akun pengguna (siswa, alumni, HRD, admin).
- `POST /api/admin/users`: Membuat akun baru.
- `PUT /api/admin/users/{id}`: Mengubah informasi akun.
- `PATCH /api/admin/users/{id}/toggle-active`: Mengaktifkan / menonaktifkan akun pengguna.
- `POST /api/admin/users/{id}/reset-password`: Reset password manual oleh Superadmin.
- `DELETE /api/admin/users/{id}`: Menghapus akun pengguna.
